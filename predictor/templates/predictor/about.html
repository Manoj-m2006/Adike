🧠 Deep Neural Network Architecture

Transfer learning with deep residual feature representations

  • Backbone: Pretrained ResNet-50 (50 layers with bottleneck residual blocks)
  • Classification Head: Modified 4-output linear layer (2048 in_features → 4 classes)
  • Input Tensor: 224 × 224 × 3 (RGB normalized via standard ImageNet mean/std)
  • Loss Function: Weighted Cross-Entropy Loss (balanced for class distribution)
  • Optimizer: AdamW with Cosine Annealing Learning Rate Scheduler
  • Inference Mode: Stateless deterministic forward pass under torch.no_grad()

⚙️ Two-Phase Training Protocol

Stable feature extraction followed by full fine-tuning

Phase 1: Feature Extraction (30 Epochs)
The convolutional backbone layers are frozen to retain general visual representations, while only the 4-class classification head is trained with learning rate 1e-3.
Phase 2: Full Fine-Tuning (20 Epochs)
All 50 residual layers are unfrozen and trained end-to-end at a gentle learning rate of 1e-5 to adapt low- and high-level filters to specific arecanut pathology features.
