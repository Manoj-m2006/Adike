🧠 Neural Network Architecture

Transfer learning with deep residual feature representations

RESNET-50

ArecaLens utilizes a fine-tuned deep residual network (ResNet-50) pretrained on ImageNet and specialized for foliar and nut pathologies of the Areca catechu palm.

  • Backbone: 50 convolutional layers with residual shortcut connections solving vanishing gradients
  • Classification Head: Modified 4-output linear layer (2048 → 4 classes: Healthy Leaf, Healthy Nut, Mahali, YLD)
  • Input Tensor: 224 × 224 × 3 (RGB normalized via ImageNet μ=[0.485, 0.456, 0.406], σ=[0.229, 0.224, 0.225])
  • Explainability: Grad-CAM targeted at the terminal residual block (layer4, 2048 bottleneck channels)
  • Inference Mode: Deterministic forward evaluation under torch.no_grad() with sub-100ms execution latency

🔍 Explainable AI (Grad-CAM)

Gradient-weighted Class Activation Mapping

XAI PROTOCOL

To provide actionable transparency for growers and agronomists, the model computes neuron importance weights by taking gradients of the target class score with respect to feature activation maps of the final convolutional layer:

αkc = (1/Z) ∑i ∑j (∂ yc / ∂ Ai,jk)
LGrad-CAMc = ReLU( ∑k αkc Ak )

The positive rectification (ReLU) isolates visual features that contribute positively to the predicted pathology, rendered as a continuous thermal heatmap blended over the original specimen image at 45% default opacity.
